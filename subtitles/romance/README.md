# Romance subtitles / ترجمة الرومانسي

Put the .vtt subtitle files for the romance series "A Second Chance" (فرصة ثانية) here, e.g.:

- `episode1_en.vtt` — English subtitles (primary dialogue)
- `episode1_ar.vtt` — Arabic subtitles (translation)

Then set `subtitles_en_url` / `subtitles_ar_url` in `videos.json` to:
https://raw.githubusercontent.com/adam2211dmdm-ux/cinereels-videos/main/subtitles/romance/episode1_en.vtt

Do NOT invent subtitle files for episodes with no dialogue yet — sc-ep1/sc-ep2/sc-ep3 currently have null subtitle URLs in the manifest until real subtitles are written.
